🔄 Sıkıcı Veri Dönüştürücü Merkezi

Bu sayfa vasıtasıyla Excel formatındaki envanterinizi Sıkıcı Kontrol Paneliyle tam uyumlu JSON yapısına dönüştürebilir veya tam tersi işlemle JSON verilerinizi Excel tablosuna geri çekebilirsiniz.

📊 1. Adım: Excel Verilerini JSON Yapısına Çevir

Nasıl Yapılır? Excel sayfanızdaki verileri (Başlık satırı dahil olacak şekilde) fareyle seçip kopyalayın (Ctrl+C). Aşağıdaki kutuya yapıştırın (Ctrl+V) ve dönüştür butonuna basın.

📋 Doğru Eşleşme İçin Excel Sütun Rehberini Göster

Excel sayfanızın ilk satırındaki (başlıklar) isimlerin aşağıdaki kelimeleri içermesi veya bu sırada olması dönüşümün hatasız olmasını sağlar:

Sütun No (Sıra) Önerilen Excel Başlık Adı Sistem Karşılığı / Açıklama
1seriNoSeri Numarası (Benzersiz ID)
2idNoFabrika İç ID No (Örn: TT-123)
3markaÜretici Marka
4modelCihaz Modeli
5torkTork Aralığı (Örn: 10-50 Nm)
6tipElektrikli, Bataryalı veya Pnömatik
7hatBulunduğu Üretim Hattı
8istasyonİstasyon / AGP Bilgisi
9sorumluOperasyon Alan Sorumlusu
10kalibrasyonSon Kalibrasyon Tarihi
11durumAktif, Arızalı, Yedek, Kalibrasyonda

16gorselGörsel Resim URL Linki

🎉 Dönüşüm Başarılı! Oluşturulan JSON Verisi:

Aşağıdaki çıktıyı kopyalayıp bir dosyaya kaydedebilir veya doğrudan bilgisayarınıza indirebilirsiniz.
